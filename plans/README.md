- Bind live mode only to 127.0.0.1. Do not add accounts, remote transport, pairing, synchronization, or a remote control plane.

- Keep root/subagent IDs session-local where designed and retain composite cache keys. Exclude codex-auto-review guardian/approval rows from normal conversation counts and filters.

- Use PNPM directly so progress remains visible. On Windows, rerun an exact build/E2E command in a normal elevated shell when Nitro tracing fails only because profile readlink access is denied.
- Do not stage, commit, create a branch, use a worktree, push, or open a pull request unless the operator explicitly authorizes that Git operation.

## Findings considered and rejected

- Malformed PNPM lockfile: rejected. PNPM 11's two-document lockfile shape is expected, and a frozen offline resolution accepted the lockfile before stopping only on a missing local tarball.
- TypeScript 7 migration: rejected until the Vue/embedded-language programmatic API is stable; remain on TypeScript 6.
- H3 2 migration: rejected while the available line is a release candidate and Nuxt uses the tested H3 1.15 SSE contract.
- Immediate wholesale LiveReconciler split: deferred. First land the revision and changed-only behavioral seams; refactor only where those changes prove a stable boundary.
- Authentication for current live mode: rejected under the explicit loopback-only local boundary. Reassess immediately if binding expands beyond loopback.
- Blanket dependency upgrades: rejected. Patch upgrades can be taken opportunistically with normal verification; they do not justify separate plans.
