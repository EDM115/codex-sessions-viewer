# Dependency upgrade compatibility review (2026-10-27)
The staged dependency upgrades are retained and their necessary compatibility fixes are implemented in the working tree. No staging, unstaging, commit, branch or worktree operation was performed. This review is separate from the product implementation plan.  
The old/new columns describe the staged manifest versions (without repeating their unchanged `~` prefixes), not a claim about a previously running installation. All 25 changed direct dependencies are installed at their requested target versions. PATH Node reports `v26.12.1`, pnpm reports `11.28.9`, and the project engine remains `>=26 <27`.

## Implemented compatibility fixes
| Problem and evidence | Fix | Files |

Typecheck failed with TS5052 in both configs | Explicitly set the existing decorator option through `typescript.nodeTsConfig` and `typescript.sharedTsConfig` | `nuxt.config.ts` |

| H3 2 `eventStream.send()` returns a ReadableStream. The helper discarded it, producing HTTP 404 in the actual SSE transport test | Make the helper generic over the send result and propagate it through the helper, route and integration fixture, preserving H3 1's Promise<void> behavior and disconnect cleanup | `server/live/eventStream.ts`, `server/api/events.get.ts`, `tests/integration/live/invalidationBus.test.ts` |
Existing HTTP integration cases failed before the response fixes and passed afterward. No Codex source files or `.codex` data were modified.

## HTTP runtime boundary
Nuxt 4.6.3 defaults to Nitro 2.13.5 with H3 1.15.11. Installed `@nuxt/nitro-server/dist/index.mjs` resolves its own H3 at lines 953-954 and aliases it in the Nitro bundle at lines 1134-1135. Generated server type paths follow that runtime. Standalone integration tests resolve the direct H3 2.0.8 dependency. A root H3 upgrade therefore does not make Nuxt 4's server runtime H3 2. Both paths need coverage, the response fixes work in both. No alias override or dependency downgrade was introduced. [Nuxt 4.6 release](https://github.com/nuxt/nuxt/releases/tag/v4.6.0), [H3 migration guide](https://h3.dev/migration).  
Nuxt 4.6's `nuxt/server` surface offers a portable future migration path. Migrating every route is unnecessary for these upgrades. The H3 migration page still includes an outdated beta note, installed 2.0.8 and official stable release notes establish target status. [H3 2 announcement](https://h3.dev/blog/v2).
