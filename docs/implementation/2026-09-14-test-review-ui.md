# UI, content, timeline and browser test review — 2026-09-14

Scope: every current test in `tests/unit/ui`, `tests/unit/content-rendering`, `tests/unit/timeline` and `tests/e2e`, including existing tests predating this implementation. Applied the discriminating-testing skill: identify the plausible wrong implementation, challenge it with asymmetric inputs or ordered state transitions, and inspect the expected-value oracle. This review changes tests only. It does not modify production code, Git state, source Codex data, or screenshot baselines.  
The inventory contains 27 unit suites and six browser suites. Existing smoke, cleanup, accessibility, race and resource checks are retained at their actual scope. A test's existence or a green aggregate is not treated as proof of an unexercised behavior.
